# Changelog

All notable changes to this package are documented here.

## [1.1.0] - 2026-08-23

- Added the maintained Unity Package Manager distribution.
- Added separate Runtime and Editor assemblies.
- Added Unity 2018.4-2022.3 Git-install support.
- Retained Unity 2017-2022 source-level API compatibility fallbacks.
- Removed the hard URP package dependency from the included outline shader.
- Added automated package-layout and compatibility checks.
