# Changelog

All notable changes to this package are documented here.

## [1.2.3] - 2026-09-25

- Added the ArtTools QQ community QR image to the repository and Package Manager details extension.
- Added Chinese package description and Chinese installation and update guidance in the README.

## [1.2.2] - 2026-09-24

- Preserved the selected output folder and sequence settings when entering Play mode.
- Opened the output folder with the last exported frame selected when a sequence finishes.
- Added a configurable shortcut for single-image capture.

## [1.2.1] - 2026-09-17

- Integrated scene placement into the Decoration Tool generator workflow.
- Added selectable scene-placement Profiles with mixed placement support.
- Added horizontal and circular placement controls plus scene-view wheel shortcuts.
- Kept generated objects grouped under their own named parent objects.
- Hid the standalone Prefab Placer hub entry and the overlapping vertical placement option while retaining their underlying implementation.

## [1.2.0] - 2026-08-24

- Added a Missing Script checker to the unified Art Tools hub.
- Added explicit folder selection and optional full-Assets Prefab scanning.
- Added missing counts, node paths, Prefab opening, and automatic missing-node selection.
- Kept `Art Tools > 美术工具中心` as the package's only top-level Art Tools menu entry.
- Refined the checker window to a compact 420-pixel default width with a clear primary scan workflow.

## [1.1.0] - 2026-08-23

- Added the maintained Unity Package Manager distribution.
- Added separate Runtime and Editor assemblies.
- Added Unity 2018.4-2022.3 Git-install support.
- Retained Unity 2017-2022 source-level API compatibility fallbacks.
- Removed the hard URP package dependency from the included outline shader.
- Added automated package-layout and compatibility checks.
